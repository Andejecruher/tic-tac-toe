🐱 Juego del Gato (Tic-Tac-Toe)

Un clásico Juego del Gato desarrollado con HTML, CSS y JavaScript, pensado para practicar fundamentos de programación y manipulación del DOM.

✨ Características

🎮 Dos jugadores (❌ y ⭕) en el mismo dispositivo.

🧩 Detección automática de ganador o empate.

🔄 Botón para reiniciar la partida.

🎨 Diseño simple y responsivo con CSS puro.

🚀 Tecnologías

HTML5 → estructura del tablero.

CSS3 → estilos y diseño visual.

JavaScript → lógica del juego.

📌 Próximas mejoras

✅ Animaciones en las casillas al marcar.

✅ Contador de partidas ganadas.

🌐 Versión multijugador en línea.

🤖 Implementación de un modo contra la computadora.
